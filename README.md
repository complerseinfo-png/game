# game

ブラウザで遊べる自作ゲーム置き場です。GitHub Pages で公開しています。

| ゲーム | フォルダ | 内容 |
| --- | --- | --- |
| エアコン リモコン ごっこ | `aircon/` | 架空メーカー4社のエアコンとリモコンを操作して遊ぶ。リモコンの作りはメーカーごとに違う。 |
| ふきとばせ！せんぷうき | `fan/` | 扇風機を操作して部屋のものを窓から吹き飛ばす3Dゲーム。電池を集めると5段階でパワーアップ。 |
| ねこから にげろ！ | `neko/` | ボールを操作して、3匹の猫から逃げる3Dゲーム。スワイプで加速、逆スワイプでブレーキ。 |

各ゲームは1つの HTML ファイルで完結しています。3D 表示には three.js (r128) を cdnjs から読み込んでいます。
